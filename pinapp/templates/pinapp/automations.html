Output format

What each pin contains

📌 TITLE
Under 100 characters
SEO-optimised. Includes product type, brand, key feature. No ALL CAPS or clickbait.
📝 DESCRIPTION + HASHTAGS
750–800 characters total
Copy text (~350 chars) + 15–20 high-traffic hashtags. Ends with #ad. One field, copy together.
🔎 ALT TEXT
Under 500 characters
Visual description only — colours, materials, shapes. No promotional language.
📋 BOARD NAME
One suggested board
Matches a high-volume Pinterest search. Specific enough for a niche board of 50+ pins.
🛒 AMAZON LINK
amazon.in deeplink
Direct product URL. Opens Amazon India app on mobile. Tracks via affiliate tag.
🖼️ IMAGE
1500px hi-res
Upgraded from thumbnail via URL rewrite. Sharp, pin-worthy quality automatically.
