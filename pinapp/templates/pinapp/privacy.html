Privacy Policy

Last updated: October 2026

Welcome to Pin Orbit. This Privacy Policy describes how Pin Orbit ("we", "our", or "the app") handles data when connecting with Pinterest services through the Pinterest API.

1. Purpose of the Application

Pin Orbit is an internal personal automation tool designed to create, format, and publish product Pins directly to authorized personal Pinterest boards.

2. Data Collection and Usage

  • Pinterest Account Data: We only access Pinterest boards and pin creation endpoints authorized by the account owner using official OAuth2 access tokens.
  • No Selling of Data: We do not sell, rent, or share any personal user information, Pinterest data, or analytical tokens with third parties.
  • Token Storage: API credentials and access tokens are stored securely in encrypted server environment variables and are solely used to authenticate pin publication requests.
  • Third-Party Services: The application may interact with Amazon and Google Gemini APIs solely for product metadata and generating SEO pin descriptions.

3. Data Retention and Revocation

You can revoke access to this application at any time directly through your Pinterest account security settings or by deleting your API access token.

4. Contact Us

If you have any questions about this Privacy Policy, please contact the developer via your Pin Orbit dashboard administrator contact.
